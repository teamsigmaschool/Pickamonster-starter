# Pickamonster starter

The screens are here, styled, showing two sample cards. Nothing is connected yet: no database, no
game, no leaderboard. That is the project.

React (Vite) in `frontend/`, Express in `backend/`, Supabase for Postgres, Storage and Auth.

## Run it

1. In `backend/`: `npm install`, then copy `.env.example` to `.env` and fill it in.
2. In `frontend/`: `npm install`, then copy `.env.example` to `.env` and fill it in.
3. `npm run dev` in both, and open http://localhost:5173.
